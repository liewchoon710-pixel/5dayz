# ShichengWuri · 尸城五日

僵尸末日生存网页游戏（试玩版）。打开 GitHub Pages 链接即可在手机/电脑上玩。

- `index.html` — 游戏本体
- `assets/` — 游戏用的网页素材（glb 模型、贴图）
  - `chars/` 人物与丧尸（Quaternius Zombie Apocalypse Kit，CC0）
  - `props/` 集装箱、巴士、叉车、自动售货机、门、沙发、电视柜、椅子、笔记本、单车（从上传的模型包转换并减面）
  - `tex/` 建筑外墙照片贴图
- 根目录的 .rar / .zip — 原始素材包（保留不动）

`cdn` 分支只放 `assets/` 的内容，供 jsDelivr 给 Claude 里的版本加载。
